{{/* "Last updated" stamp — the timestamp of the NEWEST story in scope, i.e. the moment the site was last updated with new stories. Deliberately NOT the reader's clock (Robert, 2026-10-23) and not the raw deploy time either: a 6am rebuild with no new story would otherwise claim a fresh edition. Call with a dict so the stamp can be scoped to the page: home page -> all published stories category page -> that category's stories Stories carry an explicit -04:00/-05:00 offset; time.In normalises to Eastern so Go prints the EDT/EST abbreviation instead of a bare offset. */}} {{ $pages := .pages }} {{ with $pages }} {{ $latest := index . 0 }} {{ range . }}{{ if gt .Date $latest.Date }}{{ $latest = . }}{{ end }}{{ end }} {{ $t := $latest.Date | time.In "America/New_York" }}

Last updated {{ $t | time.Format "Monday, January 2, 2006 — 3:04 PM MST" }}

{{ end }}
